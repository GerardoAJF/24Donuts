# 24Donuts
Sistema para la gestión de una cafeteria 24/7

## ¿Cómo ejecutar el aplicativo?:
Primero debe configurar el archivo `.env` del backend, en el archivo `config.js` puede ver las variables de entorno requeridas.
Debe ejecutar el comando `npm run dev` dentro de la carpeta backend y frontend.
En ese momento debería de poder ver el sistema web, si no ve nada, pruebe borrando la cache.

## Herramientas utilizadas:
Backend:
- mongoDB
- NodeJs

Frontend:
- ReactJs

## Estructura del proyecto:
El proyecto está separado en 2 carpetas, backend y frontend.
A su vez la carpeta frontend está separada en componentes y páginas, las cúales están separadas en privadas (para el admin), publicas (para el cliente) y compartidas (que se encuentran en ambos sistemas)
